## Treat as Generated Output

The following directory is generated by training, evaluation, probing, or plotting scripts:

```text
onpolicy/scripts/results/
```

It currently contains:

- model checkpoints (`*.pt`)
- value normalizer checkpoints (`vnrom_agent*.pt`)
- fixed-opponent metrics (`fixed_opponent_metrics.json`)
- cutoff-intervention summaries (`cutoff_intervention_summary.json`)
- role-analysis outputs (`*.pkl`, `*.json`, `*.png`)
- final report figures (`*.png`, `*.pdf`, `*.tex`)

For a class project repository, it is usually better to keep only final lightweight result summaries and figures in Git, while storing heavy checkpoints elsewhere.

## Large Files to Remove From Git Before Final Submission

The most important cleanup target is:

```text
onpolicy/scripts/results/**/models/*.pt
onpolicy/scripts/results/**/*.pkl
onpolicy/scripts/results/**/logs/
onpolicy/scripts/results/**/wandb/
```

These files are useful locally, but they make the repository heavy and are not necessary for reading or grading the code.

## Suggested `.gitignore` Direction

After moving final figures/tables into `results_summary/`, the repository can ignore most generated outputs:

```gitignore
onpolicy/scripts/results/
!results_summary/
!results_summary/figures/
!results_summary/tables/
```

If model checkpoints must be preserved, use one of these options instead of committing all checkpoints:

- GitHub Releases
- Google Drive / Box link in README
- Hugging Face dataset/model storage
- a small representative checkpoint only

## Safe Cleanup Workflow

Use a branch first:

```bash
git checkout -b project-cleanup
```

Then move final figures/tables to a lightweight summary directory:

```bash
mkdir -p results_summary/figures results_summary/tables
cp onpolicy/scripts/results/MPE/simple_tag/mappo/base_reward_bandwidth_sweep/*.{png,pdf,tex} results_summary/figures/
cp onpolicy/scripts/results/MPE/simple_tag/mappo/base_reward_cutoff_intervention/*.{png,pdf,tex} results_summary/figures/
cp onpolicy/scripts/results/MPE/simple_tag/mappo/base_reward_role_analysis/*.{png,pdf} results_summary/figures/
```

Then remove generated artifacts from Git tracking:

```bash
git rm -r --cached onpolicy/scripts/results
```

Finally update `.gitignore`, add the lightweight summaries, and commit:

```bash
git add README.md docs results_summary .gitignore
git commit -m "Organize project repository"
```

Do not rewrite Git history unless repository size itself becomes a problem on GitHub. If needed, use `git filter-repo` carefully on a backup clone.
